# Лабораторна №2 — Маршрутизація та шаблони

Особиста сторінка Михайла Венгриновича українською: резюме `/` та контакти `/contacts`.

## Локальний запуск

У PowerShell із кореня проєкту, використовуючи наявне віртуальне середовище:

```powershell
.\.venv\Scripts\python.exe -m flask run
```

Відкрити `http://127.0.0.1:8080/` та `http://127.0.0.1:8080/contacts`.
Збережено `.flaskenv`: `FLASK_APP=app.py`, `FLASK_DEBUG=1`, `FLASK_RUN_PORT=8080`.
Збережено також прямий запуск `python app.py` із `app.run(debug=True)` (типовий порт 5000) та об’єкт `app`, потрібний для `gunicorn app` на Linux / Render. Залежності не змінені.

## Відповідність вимогам

- Обидва маршрути використовують `render_template` і передають `title` із Python.
- `resume.html` та `contacts.html` наслідують `base.html`; у ньому є блоки `title` і `content`.
- Меню та футер — спільні компоненти, підключені через `include`.
- П’ять секцій резюме мають окремі `section` та `id`: `about`, `education`, `skills`, `technologies`, `projects`.
- Якорі будуються як `url_for('main', _anchor='about')`, тому працюють із контактів також.
- Посилання на сторінки, власний CSS та зображення формуються через `url_for`.
- Bootstrap 5.3.8 (CSS і bundle з jsDelivr CDN) доповнений власними стилями, адаптивною сіткою та мобільним меню. Для завантаження Bootstrap потрібен інтернет. [Офіційна документація Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/).
- Контакти без відомих значень позначено «Додати контакт». Досвід і рівні навичок не вигадані.
- Фото відсутнє: `static/images/avatar.svg` — локальна нейтральна заглушка. Її потрібно замінити власною фотографією та оновити `filename` й `alt` у `resume.html`.
- База даних, авторизація та додаткові Python-бібліотеки не додані.

## Форма-заглушка

Форма має поля «Ім’я», «Email», «Повідомлення». Кнопка «Перевірити форму» виконує порожній POST на той самий маршрут і показує: «Надсилання поки не реалізоване. Повідомлення не надіслано, дані не збережено».

Поля навмисно не мають атрибута `name`, тому браузер не включає їхні значення в запит. `novalidate` дозволяє показати повідомлення-заглушку за будь-якого вводу. Python перевіряє тільки метод запиту; не читає `request.form`, не зберігає й не надсилає повідомлення. Сторонні сервіси для форми не використовуються.

## Перевірки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Шість тестів через Flask test client перевіряють сторінки, заголовки, спільний каркас, п’ять секцій і якорі з обох сторінок, CSS та валідний SVG, структуру форми, порожній і заповнений POST, об’єкт Flask та підключення мобільного меню. Сторінки й статичні ресурси повинні повертати HTTP 200.

Test client не виконує JavaScript і не перевіряє візуальне оформлення або завантаження Bootstrap із CDN.

## Пояснення для захисту

- `route` зв’язує URL із Python-функцією: `@app.route('/')` викликає `main()`.
- `render_template` створює HTML із шаблону й переданих даних, наприклад `title`.
- `extends` наслідує спільний шаблон: `{% extends 'base.html' %}`.
- `block` визначає область, яку дочірній шаблон може заповнити; тут це `title` і `content`.
- `include` вставляє спільний фрагмент, наприклад навігацію чи футер.
- `url_for` будує адресу за назвою функції маршруту або статичного файла; `_anchor` додає якір секції.
