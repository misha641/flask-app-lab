# Лабораторна №3 — Модульна структура. Blueprints

Flask-застосунок із резюме й контактами Михайла Венгриновича, головною сторінкою, привітаннями та каталогом трьох товарів. Використано простий екземпляр `app`, без фабрики застосунку, бази даних і авторизації. Залежності попередньої лабораторної не змінено.

## Структура

```text
flask_app_Venhrynovych/
├── run.py
├── config.py
├── .flaskenv
├── .gitignore
├── requirements.txt
├── README.md
├── app/
│   ├── __init__.py
│   ├── views.py
│   ├── templates/
│   │   ├── base.html
│   │   ├── homepage.html
│   │   ├── resume.html
│   │   ├── contacts.html
│   │   └── components/ (navigation.html, footer.html)
│   ├── static/
│   │   ├── css/styles.css
│   │   └── images/ (avatar.svg, images.jpg)
│   ├── users/
│   │   ├── __init__.py
│   │   ├── views.py
│   │   └── templates/users/hi.html
│   └── products/
│       ├── __init__.py
│       ├── views.py
│       └── templates/products/ (products.html, detail_product.html)
└── tests/
    ├── test_app.py
    ├── test_user_bp.py
    └── test_products_bp.py
```

`app/__init__.py` створює Flask-застосунок, завантажує `config.py`, імпортує основні маршрути та реєструє два Blueprint. Імпорти маршрутів розташовані після створення `app`/Blueprint. Усі сторінки наслідують загальний `base.html`; посилання будуються через `url_for`.

## Запуск у PowerShell

Із кореня проєкту, використовуючи наявне `.venv`:

```powershell
.\.venv\Scripts\python.exe -m flask run
```

`.flaskenv` містить `FLASK_APP=run.py`, `FLASK_DEBUG=1`, `FLASK_RUN_PORT=8080`. Альтернативний прямий запуск також використовує порт 8080:

```powershell
.\.venv\Scripts\python.exe run.py
```

Зупинка сервера — `Ctrl+C`. Конфігурація не містить секретів. `.venv`, `.env`, кеш Python та локальна методичка `lab3.pdf` виключені з Git.

## Сторінки для перевірки

| URL | Очікувана поведінка |
| --- | --- |
| http://127.0.0.1:8080/ | Резюме з п’ятьма секціями |
| http://127.0.0.1:8080/contacts | Контакти та форма-заглушка |
| http://127.0.0.1:8080/homepage | Головна з User-Agent браузера |
| http://127.0.0.1:8080/users/hi/John?age=30 | JOHN, вік 30, вертикальне меню |
| http://127.0.0.1:8080/users/hi/John?age=0 | Вік 0, а не повідомлення про відсутність віку |
| http://127.0.0.1:8080/users/hi/John | Вік не вказано |
| http://127.0.0.1:8080/users/admin | 302 на `/users/hi/administrator?age=45` |
| http://127.0.0.1:8080/users/hi/administrator?age=45 | ADMINISTRATOR, вік 45 |
| http://127.0.0.1:8080/products/ | Laptop — 1200, Phone — 800, PC — 1800 |
| http://127.0.0.1:8080/products/1 | Laptop, повний опис |
| http://127.0.0.1:8080/products/2 | Phone, повний опис |
| http://127.0.0.1:8080/products/3 | PC, повний опис |
| http://127.0.0.1:8080/products/999 | 404 Not Found |
| http://127.0.0.1:8080/static/css/styles.css | CSS |
| http://127.0.0.1:8080/static/images/avatar.svg | Зображення |

У `users.greetings` ім’я переводиться у верхній регістр, а вік читається через `request.args.get("age", None, int)`. Відсутній або некоректний вік відображається як невказаний. Перевірка `age is not none` зберігає значення 0. Вертикальне меню є тільки у `hi.html`. Маршрут `users.admin` використовує `redirect(url_for('users.greetings', ...))`.

Список словників `products` зберігається в `app/products/views.py`. Описи перенесено з методички дослівно, валюту не додано. Невідомий ідентифікатор обробляється через `abort(404)`.

## Збережена поведінка лабораторної №2

Резюме, контакти, зображення, стилі, спільний футер та якорі секцій збережено. Меню доповнено посиланнями на нові сторінки. Bootstrap 5.3.8 завантажується з CDN, тому для його стилів і мобільного меню потрібен інтернет.

Форма контактів залишається заглушкою: поля не мають `name`, `novalidate` дозволяє порожній POST. Сервер не читає, не зберігає та не надсилає введені дані, а показує повідомлення про нереалізоване надсилання.

## Тести

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

17 тестів стандартної бібліотеки `unittest` із Flask `test_client` перевіряють:

- Збережені шість перевірок лабораторної №2: сторінки, спільний каркас, секції та якорі, статичні ресурси, форму і підключення мобільного меню.
- `/homepage`, відображення й HTML-екранування User-Agent, навігацію з усіх сторінок.
- Привітання, точну адресу редіректу, перехід із `follow_redirects=True`, нульовий, відсутній і некоректний вік, меню тільки на сторінці привітання.
- Три товари в списку, відповідність кожного id назві, ціні й точному опису, 404 для невідомих id.

Усі 17 тестів пройшли. Test client не виконує JavaScript і сам по собі не перевіряє візуальне оформлення.

Окремо перевірено браузером: резюме, контакти, головну, привітання, перехід адміністратора, каталог, усі три детальні сторінки та очікуваний 404. Перевірено мобільне меню й перехід із контактів до секції резюме; на ширині 390 px нові сторінки не мають горизонтального переповнення. Переглянуто скріншоти головної, привітання, каталогу й мобільної детальної сторінки. У консолі був 404 для відсутнього `favicon.ico`; функціональні перевірки пройшли.
